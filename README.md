# Conversor XLSX a CSV 📊

Este proyecto permite convertir archivos `.xlsx` a `.csv`, procesando columnas específicas y asegurando que los valores se mantengan correctamente.

## 🚀 Características:
- Extrae datos de un archivo `.xlsx` y los guarda en `.csv`
- Mantiene los números sin perder ceros ni formato
- Se detiene en la primera fila vacía de las columnas requeridas
- Calcula el balance total de los valores extraídos
